# First use

1. Install the versioned plugin ZIP linked in README through WordPress Plugins, not GitHub's generated source ZIP. Existing installs should use Replace/Update, not Delete.
2. Providers: select a connection, privately enter its key, choose a model currently available to your account, save. Model names/IDs are a bundled snapshot; Manual override is available. Custom/local adapters require an approved public HTTPS Chat Completions URL. A blank key field keeps the existing encrypted key at its original destination.
3. Training: check eligible public-source scopes/exclusions and factual accuracy. Fresh installs include public posts/pages/catalog; existing opt-outs remain. Imports/admin teaching require review. Instruction collection holds bounded administrator guidance, not model retraining.
4. Widget: choose branding, one of ten themes through Settings, position/offsets and bounded sizes. Preview is unsaved and message-free. New image IDs require server validation on save. Niche selection is only a suggestion until deliberately applied and saved.
5. Notifications: choose Email, Telegram or HTTPS relay. Use the inline step-by-step guide. Email needs your working WordPress mail setup. Telegram tokens come from the official BotFather; destination IDs come from your own securely handled Bot API updates. Group/channel permissions and existing webhooks matter. Never put tokens in browser URLs or public reports. Alerts are outbound; no two-way Telegram/WhatsApp support channel is provided.
6. Overview: deliberately enable customer chat only after checking privacy wording, provider terms/quotas and fictional responses. Saved settings alone are not a connection success result.
7. Chat Inbox capture/intake/analysis remain separate deliberate controls. Future capture needs the existing consent flow. Reply/takeover actions retain admin guards; no model can grant commerce access.
8. WooCommerce: verify two normal test accounts, their own purchases, cross-account rejection and native Downloads/file permissions. The account-page link does not protect a publicly hosted file.

Use synthetic staging data and your own approved notification destinations for verification. This release process does not install on any live website, send provider/customer messages, make purchases or alter site security settings.
